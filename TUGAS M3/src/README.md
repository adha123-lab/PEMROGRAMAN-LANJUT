# Nota Pemesanan Restoran 

Program ini merupakan versi Tugas 3 Modul 3 Pemrograman Lanjut.

##  Fitur Baru
1. Tambah menu minuman
   - Pengguna bisa memesan makanan dan minuman sekaligus.
2. Simpan nota ke file .txt
   - Setelah program dijalankan, hasil nota otomatis disimpan dalam file `nota.txt`.

## Cara Menjalankan
1. Jalankan file `NotaRestoran.java` di IntelliJ IDEA atau terminal.
2. Masukkan data makanan dan minuman sesuai perintah.
3. Lihat hasil nota di konsol dan di file `nota.txt`.

## Tujuan
- Menerapkan Git branch untuk pengembangan fitur baru.
- Melatih penggunaan I/O file di Java.
- Memahami proses version control (commit, push, branching).

## Teknologi yang Digunakan
- Java
- IntelliJ IDEA
- Git & GitHub
